# Security Eye

Responsive front-end website for a CCTV and smart-security store.

## Pages
- `index.html` — home page
- `products.html` — product catalogue with category filters and live search
- `product-details.html` — product gallery and quantity selector
- `services.html` — services
- `about.html` — about the business
- `contact.html` — contact information
- `login.html` / `signup.html` — presentation-only forms

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Notes
- Product cart data is stored in browser `localStorage`; it is a front-end demo and is not connected to checkout or a server.
- Login and sign-up forms are visual only. Real authentication, order processing, and payment require a secure backend.
- Product names, prices, contact details, and service claims should be verified before publishing.
